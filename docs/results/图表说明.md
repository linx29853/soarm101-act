# README 图表来源与复现

图表由已有日志与离线评估文件生成，未重新训练或驱动机械臂。

| 图表 | 保存的数据 |
|---|---|
| training_validation | chart_data/training_metrics.csv、chart_data/validation.jsonl |
| prediction_horizon | chart_data/evaluation_summary.json 中 validation.horizons |
| strategy_comparison | 同上 validation.modes |
| joint_traces | chart_data/episode_000012.npz、episode_000099.npz |
| chunk_discontinuity | evaluation_summary.json 中 validation.execution_sweep |

原始训练日志：outputs/logs/act_blue_cube_180train_100k.log。共 1,000 条损失记录，按配置 log_freq=100 恢复精确步数 100～100000；原日志的取整步数标签同时保留在 CSV 中。移动平均使用 20 个记录点，未修改原始损失。

检查点验证来源：outputs/train/act_blue_cube_180train_100k/validation.jsonl。每条示范抽取 10 个观测，比较完整动作块；不同于完整 9,447 帧回放的执行策略指标。

回放汇总及轨迹来源：outputs/evaluation/blue_cube_200_diagnosis。模型为 60,000 步检查点，20 条验证示范参与过检查点选择。轨迹选择延续已有诊断中的示范 12 与 99，不是全体验证分布的代表性估计。MAE 和跳变单位均为数据集归一化关节位置；这与用于神经网络输入输出标准化的 z-score 不同。

重绘（需 NumPy、Matplotlib）：

```bash
python scripts/plot_readme_results.py
```

脚本从仓库相对路径读取附带的数据，输出到 docs/results/assets/charts/，每图同时保存 PNG 和 SVG。图中英文标签便于 GitHub 显示，中文解释保留在 README。
