# 方块入盒 ACT 首轮训练

## 数据和设备

- 任务：抓起方块并放入盒子。
- 数据集：`local/so101_task`，本地目录 `data/datasets/so101_task`。
- 50 条示范，16435 个时间步，100 个相机视频；数值文件行数与元信息一致，文件存在性和非空检查通过。
- 相机：`front`、`handeye`，640×480，数据集标注频率 30 Hz。
- 关节状态与动作均为 6 维，`use_degrees=false`。
- 设备：RTX 5070 Laptop，约 8 GB 显存。
- LeRobot 基线：`882c80d446a63a44868c67ae535467af32ce0e80`，应用项目补丁。

## 采集

```bash
bash scripts/bootstrap.sh
bash scripts/record_cube_50.sh
```

脚本默认使用 `$HOME/miniconda3/envs/lerobot/bin/python`，可通过 `SOARM_PYTHON` 指定解释器。串口、相机路径和机械臂名称按采集工作站配置保存在脚本中；运行前应与实际设备对应。校准文件使用 `my_awesome_follower_arm` 和 `my_awesome_leader_arm`，部署在对应账户的 LeRobot 校准目录。

正式采集脚本读取已保存条数，续录至总计 50 条。录制和复位各最多 60 秒；录制终端获得焦点时，右方向键或 `n` 进入下一阶段，左方向键或 `r` 重录当前条，Esc 或 `q` 结束。复位期间主从跟随持续运行，复位过程不写入示范数据。

场景相机启用 MJPEG 以降低 USB 带宽占用。双相机接口测试在约 8 秒内返回 164 组画面；后续检查应同时关注实际采集频率与时间戳。实时预览关闭，避免预览进程占用大量内存；双相机视频继续保存。

## 训练

```bash
PYTHONPATH=src python -m soarm101_act.cli train \
  --config configs/act_so101.json \
  --device cuda --batch-size 4 --num-workers 2 \
  --steps 20000 --save-freq 5000 \
  --output-dir outputs/train/act_so101_cube_20k \
  --effective-config outputs/configs/act_so101_cube_20k.json
```

| 项目 | 结果 |
|---|---|
| 1000 步试训练 | 完成，损失由前 100 步均值约 14.15 降至末段约 2.31 |
| 试训练参数检查 | 保存模型 244 个张量均为有限值 |
| 正式训练 | 训练状态文件记录 step=20000 |
| 检查点 | 5000、10000、15000、20000 步 |
| 最终模型 | `outputs/train/act_so101_cube_20k/checkpoints/020000/pretrained_model` |
| 正式训练日志 | `outputs/logs/act_so101_cube_20k.log` |

初期混合精度梯度统计出现非有限值，后续恢复正常；正式训练现存日志末段的损失约为 0.17～0.19。检查点步数通过 `training_state/training_step.json` 核对。
